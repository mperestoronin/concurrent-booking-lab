# Презентация семинара

SEMINAR.md содержит 9 слайдов Marp с заметками докладчика на 7,5 минуты. Это редактируемый Markdown; отдельная облачная презентация не нужна.

Откройте файл в VS Code с расширением Marp либо используйте Marp CLI. Например, при наличии Node.js:

```sh
npx --yes @marp-team/marp-cli@4.2.3 slides/SEMINAR.md -o slides/SEMINAR.html
```

Для PDF добавьте --pdf, нужен поддерживаемый браузер. Генерируемые HTML/PDF исключены из Git. Слайды используют обычный текст и таблицы порядка событий: это сохраняет совместимость Marp без плагинов Mermaid. Mermaid-диаграммы для подробного разбора находятся в docs/THEORY.md и docs/ARCHITECTURE.md и отображаются на GitHub.

Перед выступлением подготовьте вывод B02 на starter и итоговый base своего решения. Не переключайте основной рабочий каталог на старый commit во время демонстрации.
