# Топик для университетской таблицы

**Название:** «Конкурентное бронирование ресурсов с использованием PostgreSQL и Redis».

**Программа:** магистратура НИУ ВШЭ «Системная и программная инженерия» (System and Software Engineering).

**Экспертная группа:** 2 эксперта. Имена назначает организатор семинара.

**Аннотация:** студент получает работающий REST-сервис с намеренными ошибками конкурентного доступа. На реальных PostgreSQL и Redis воспроизводит гонки, исправляет временное удержание, авторизацию по токену и окончательную защиту от повторной брони. Готовое Docker-окружение и тесты с управляемым порядком операций позволяют сосредоточиться на гарантиях данных.

**Ожидаемый результат:** исправленный сервис, миграция SQL, воспроизводимые проверки, письменный отчёт и видео. Студент объясняет, какие гарантии даёт каждое хранилище и где заканчивается согласованность между ними. Дополнения: безопасное освобождение удержания и анализ истечения TTL после авторизации.

**Сложность:** до 12 астрономических часов с дополнениями; плановая разбивка 8,5 часа обязательной части (включая час резерва) и 2,5 часа дополнительной. Предварительно нужны Python, HTTP, основы SQL и работающий Docker. Знание Redis не требуется, материалы входят в топик. Оценку времени нужно подтвердить пробным прохождением.
